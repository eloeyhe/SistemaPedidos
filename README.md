# Sistema Pedidos - Diseño Orientado a Objetos

- __Materia:__ Diseño Orientado a Objetos
- __Carrera:__ Tec. en Programación de Sistemas
- __Grupo:__ Grupo N° 1

## Introducción

Este proyecto tiene como objetivo el diseño orientado a objetos de una aplicación para la gestión digital y la sincronización en tiempo real de los pedidos de Sabor Kiosco, permitiendo registrar la toma de pedidos personalizados, procesar sus pagos y controlar todo su ciclo de vida (desde que se reciben hasta que se entregan al cliente para retirar). La solución busca resolver el descontrol y los errores operativos causados por el uso de comandas físicas en papel, tales como la pérdida de papelitos, la duplicación innecesaria de preparaciones en la cocina, la omisión de pedidos, la falta de comunicación fluida entre el mostrador y la cocina, y las discusiones con los clientes en el mostrador por no tener claridad sobre qué pidieron o si ya pagaron.
