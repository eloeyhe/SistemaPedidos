# Anexo - Principios SOLID

Los principios SOLID son un conjunto de buenas prácticas aplicadas al diseño orientado a objetos que buscan lograr sistemas más organizados, mantenibles, flexibles y fáciles de extender. Su aplicación ayuda a distribuir correctamente las responsabilidades entre las clases, reducir dependencias innecesarias y evitar que los componentes del sistema estén demasiado acoplados. De esta manera, cuando sea necesario modificar, corregir o agregar una nueva funcionalidad, se pueden realizar cambios de forma más controlada, disminuyendo el riesgo de romper el sistema.
